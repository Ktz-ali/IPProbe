# IPProbe · IP 探针链接生成器

> 一个用于「确认在意之人是否平安」的轻量定位探针系统。
> 后端 PHP + MySQL，客户端 Kotlin/Compose，支持 IP 归属地定位与（访客授权的）GPS 精确定位。
>
> 作者：[消失の阿力](https://github.com/Ktz-ali) · 协议：[MIT](./LICENSE)

---

## 一、为什么做这个项目

我有个 07 年的弟弟，大学没读完被劝退了，痴迷游戏，现在在家做游戏打手接单，吃的是青春饭，不爱上班。

前阵子他在打游戏时认识了一个女孩，处了一段时间。有一天他跟家里说要去同学家玩几天、去深圳，结果中途电话也不接——其实他是去河南找那个女孩了。

这事当时只有我知道，我替他瞒着。我是怎么知道的？就是靠今天开源的这套东西：我做了一个游戏相关的网页链接发给他，他点进去之后，我确认到了他的具体位置，这才放下心，跟家里说「不用太担心他了」。

他现在挺开心的，那女孩还在上学，跟他年纪相仿，人也挺好。虽然不知道他们以后能不能成，但小年轻总得经历些事情才能成长。我选择相信她不是骗子，也真心希望多年以后，他们对感情的那份初心不会变。

**这个项目诞生的初衷，是「守护」而不是「窥探」。** 我希望它能帮到那些和曾经的我一样、想知道在意的人是否平安的人。

## 二、已实现功能

### 定位能力
- **八级 IP 归属地定位兜底链**：`pconline → chinaz → 腾讯 → 911cha → ipinfo → 百度 → 高德 → ip-api`，国内 IP 可精细到区县，多源逐级兜底，缓存 7 天 + 限流防刷。
- **离线定位**：内置 ip2region 双库（IPv4 + IPv6），无外网也能查归属。
- **GPS 精确定位**：访客授权后拿到坐标，精度 10~50 米（户外），并逆地理为文字地址（高德可到村/门牌 → 百度 → 腾讯兜底）。
- **三地图集成**：百度、腾讯（签名校验）、高德（含天气 API），Key 服务端配置。

### 探针与页面
- 多种访客模板：空白页 / 伪装 404 / 伪装 503 / 图片页 / 文字页 / 跳转页 / **天气页**。
- **天气页模板（特色）**：展示真实天气（实况 + 4 天预报），页面打开自动请求定位——「天气应用要定位」完全自然，访客零怀疑。
- 短链生成（自建 / TinyURL / clck.ru），微信内防红适配。

### 管理与数据
- 探针管理：创建 / 编辑 / 启停 / 删除，二维码分享。
- 访问日志：分页、筛选（时间 / 设备 / 国家 / 关键词）、排序、复制、CSV 导出、内置 911cha 查询、同 IP 画像、统计图表。
- 访问防护：访问码 / 有效期 / 一次性，过期自动失效。
- 多服务器管理，App 内置服务器与令牌一键连接。

### 部署
- **一键安装向导**：访问域名自动跳转安装，环境检查 → 填库信息 → 自动建表生成配置。
- `install.sql` 单文件建库，幂等可重复。

## 三、快速开始

1. 宝塔建站（Nginx + PHP 8.2 + MySQL），上传 `backend/` 到站点根目录；
2. 浏览器访问域名，跟随安装向导完成建表；
3. App 填入服务器地址与令牌，新建探针、分享链接；
4. 访客点开链接 → 记录 IP / 归属地；授权定位 → 记录精确坐标与地址。

> 详细部署见 `backend/README-BT.md` 与 `DEPLOY-CHECKLIST.md`。
